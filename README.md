# 博客信息一键填充

![logo](icons/icon128.png)

逛博客想留个言，每次都要手填昵称、邮箱、网址？填一次，以后点一下就好。

在插件里填好昵称、邮箱、网址，逛到别人博客的评论区，在「提交评论」按钮左边会出现一个黄色的「信息填充」按钮，点一下就自动填好三项，你只管写评论内容、点提交。

## 功能

- 一次填写，处处可用：昵称、邮箱、网址保存在浏览器里，不用每次重填
- 一键填充：评论区「提交评论」按钮左边的「信息填充」按钮，点一下填好三项
- 自动填充（可选）：打开评论框时自动填好，不用点按钮
- 适配多家博客：WordPress、Typecho、Hexo、Hugo、Ghost，以及 Waline、Valine、Gitalk 等评论系统
- 动态评论框也能识别：评论区是后加载的也能自动找到（MutationObserver 监听）

## 安装（2 分钟，开发模式）

> 仅在谷歌浏览器（Google Chrome）测试通过，其他浏览器未测试。

1. 下载本仓库（Code → Download ZIP），解压
2. 打开 Chrome，地址栏输入 `chrome://extensions`，右上角打开**开发者模式**
3. 点**加载已解压的扩展程序**，选中解压出来的 `blog-comment-filler` 文件夹
4. 点浏览器工具栏上的插件图标，填好昵称、邮箱、网址，点**保存**（黄色按钮）
5. 打开任意一个博客的文章页，拉到评论区，点「提交评论」左边的「信息填充」

## 适配规则

按字段名 / id / 类型 / 占位文字识别：

- 昵称：字段名含 author / nickname / name，或占位文字含“昵称 / 名字”
- 邮箱：`type="email"`，或字段名含 email / mail
- 网址：`type="url"`，或字段名含 url / website / site

如果某个博客的评论框三个字段顺序是昵称、邮箱、网址，即使字段名不规范，也会按顺序兜底填充。

某个博客不适配？提个 Issue，附上博客链接，我来改识别规则。

## 隐私

昵称、邮箱、网址只保存在你自己的浏览器里（`chrome.storage.sync`，会跟随你的 Chrome 账号同步），不会发到任何服务器，插件没有任何网络请求，不收集任何数据。

## 文件

- `manifest.json` — Manifest V3，权限只有 `storage`
- `popup.html` / `popup.js` — 插件弹窗：填信息、保存
- `content.js` — 在博客页面识别评论表单、在「提交评论」左边插入填充按钮、填充
- `icons/` — 插件 logo（16 / 32 / 48 / 128px）
